# Echo Design Language

Echo should leave Sebastian feeling calmer when he closes the app than when he opened it.

## Core Feeling

Echo should feel:

- intelligent
- calm
- futuristic
- personal
- alive
- cinematic
- effortless

## Visual Direction

Echo should feel inspired by:

- JARVIS
- Apple Intelligence
- iOS liquid glass
- reflective glass surfaces
- soft glow
- layered depth
- smooth floating panels

## Home Screen

The home screen should include:

- Echo logo
- greeting
- current time
- central animated AI orb
- subtitle: “Here’s what you missed.”
- floating glass category panels
- reflection effect beneath panels
- a “Talk to Echo” control

## Categories

- Internet
- TAMU
- Trends
- Analytics
- Today’s Best Idea
- Thought Inbox

## Avoid

- plain white document layouts
- narrow blog-style columns
- corporate dashboards
- excessive text
- flat cards
- clutter
- generic AI chatbot styling

## Interaction Style

- panels should float
- hover states should feel smooth
- cards should expand instead of opening plain pages
- transitions should be slow and polished
- the orb should subtly pulse
- the interface should feel like an operating system, not a website
